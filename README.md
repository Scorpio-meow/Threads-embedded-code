# Threads 程式碼儲存器 (Threads Code Saver)

「Threads 程式碼儲存器」是一個瀏覽器擴充功能，旨在幫助開發者與用戶輕鬆捕捉、儲存並管理 [Threads](https://www.threads.com/) 上發布的程式碼片段。當你在 Threads 上發現實用的程式碼時，可以一鍵儲存並於擴充功能彈出視窗中進行管理、搜尋、匯出與生成內嵌代碼。

## ✨ 核心功能

* **自動偵測與捕獲**：在 Threads 貼文上點擊「取得內嵌程式碼」或相關操作時，擴充功能會自動捕捉內文、程式碼區塊、作者名稱與時間。
* **強大的管理介面 (Popup UI)**：
  * **搜尋**：支援透過內文、作者、語言標籤、程式碼內容進行全域搜尋。
  * **篩選與排序**：可依照儲存時間、發文時間、作者、程式碼數量進行排序；並支援以作者、自訂標籤或貼文有效性進行篩選。
  * **單鍵複製**：快速複製單一程式碼區塊或完整的內嵌 HTML 代碼 (Embed Code)。
* **資料更新與維護**：
  * **一鍵更新**：自動開啟背景分頁，確保舊有儲存的貼文內容及發文時間是最新的，並自動標記已失效的貼文。
  * **重新生成**：當內嵌版面結構改變時，一鍵重新產生所有文章的 embed code。
* **匯出與匯入**：
  * 支援將儲存的程式碼資料庫匯出為 JSON/JS 格式，也支援匯入備份（支援合併或取代覆寫現有紀錄）。

## 📁 專案結構

- `manifest.json`: 擴充功能的設定檔 (Manifest V3)，宣告權限（storage, tabs, scripting 等）與腳本設定。
- `content.js`: 負責注入至 Threads 頁面，監聽按鈕點擊、抓取 DOM 元素、擷取貼文與對話框中的 Metadata 等。
- `popup.html` & `popup.js`: 提供擴充功能的主視窗介面與互動邏輯，包含清單渲染、資料庫操作與分頁操作。
- `styles.css`: 注入至 Threads 原生頁面的樣式 (如儲存提示動畫等)。
- `favicon.png`: 擴充功能圖示。

## 🚀 安裝指南

1. 將本專案複製 (Clone) 或下載 ZIP 並解壓縮至本地資料夾。
2. 開啟瀏覽器的擴充功能管理頁面：
   - Google Chrome: `chrome://extensions/`
   - Microsoft Edge: `edge://extensions/`
3. 在右上角或左下角開啟 **「開發人員模式 (Developer mode)」**。
4. 點擊 **「載入未封裝項目 (Load unpacked)」** 按鈕，選擇本專案所在的資料夾 (`threads-embedded-code`)。
5. 安裝完成！建議將擴充功能釘選在工具列上方便後續使用。

## 💡 使用方式

1. **儲存程式碼**：瀏覽 Threads 上的貼文時，點擊原文提供的選項（如「取得內嵌程式碼」），擴充功能會在背後自動擷取並儲存該篇貼文的資訊與程式碼。
2. **管理與搜尋**：點擊瀏覽器右上角的擴充功能圖示，即可開啟管理面板，尋找過往儲存的程式碼紀錄。
3. **更新狀態**：在彈出視窗中點擊「更新資料」，擴充功能將會自動在背景取得每一篇有效貼文的最精確發文時間與內容，讓你的歸檔資料保持最新。
4. **生成 Embed Code**：點選「匯出」按鈕取得精簡版內嵌代碼，或點擊「複製內嵌程式碼」將 Threads 貼文轉化為可以放在個人部落格或網站上的 HTML `<blockquote class="text-post-media">` 代碼。

## 🛠 開發注意事項

- 本擴充功能依賴 DOM 結構。如果 Threads 網站更新了其發文 DOM 結構、CSS Classes (`.xo1l8bm`, `.xi7mnp6`) 等，`content.js` 內的解析邏輯可能需要進行相應的更新。
- 更新資料等功能使用了 `chrome.scripting.executeScript` 與隱藏的 background tabs。在處理大量更新時請注意速率與系統負載。
